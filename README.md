# 🎫 Support CRM – Ticket Management System

A modern **Support CRM and Ticket Management System** built for managing customer support tickets efficiently.

The application allows users to create, view, search, filter, and update support tickets through a clean and responsive dashboard.

## 📌 Project Overview

Support CRM is a web-based ticket management system developed using **Python, FastAPI, SQLAlchemy, SQLite, HTML, Tailwind CSS, and JavaScript**.

The system provides a centralized dashboard where support teams can manage customer issues and track ticket status.

### Main Ticket Statuses

- 🟢 Open
- 🟡 In Progress
- 🔵 Closed

---

## ✨ Features

- 🎫 Create new support tickets
- 📋 View all tickets
- 🔍 Search tickets
- 🔽 Filter tickets by status
- 👁️ View complete ticket details
- 🔄 Update ticket status
- 🗑️ Delete tickets
- 🆔 Automatic Ticket ID generation
- 📊 Dashboard statistics
- 📝 Ticket notes support
- ⚡ RESTful API
